# AERIS 1.2.3

The gadget's upper memory bar now uses stacked app colors, matching its resource breakdown.

- The filled width retains actual physical memory usage; the unfilled right side remains free capacity.
- Colors within the used area follow measured process-memory proportions, using the same app colors as the lower breakdown.
- Labels and hover descriptions distinguish process proportions from physical RAM allocation, including shared-memory overlap.
- The upper bar always shows memory, independently of the lower CPU/MEM selector.

Windows x64 installer/portable ZIP, macOS Apple Silicon/Intel DMGs and Linux x64 DEB/AppImage are built and tested by GitHub Actions. Each package includes a SHA-256 sidecar. Windows builds are unsigned; macOS builds use ad-hoc signing without notarization. The interface is Japanese.
