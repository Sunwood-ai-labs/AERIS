# AERIS 1.2.1

See which processes use the most CPU and memory at a glance.

- Cyan CPU bars and violet memory bars compare processes without hiding the actual percentage or memory amount.
- Top-consumer shortcuts take you directly to the highest-usage CPU or memory process.
- Amber/red accents and warning symbols highlight high absolute usage. Search and sorting preserve the comparison scale across the entire snapshot.
- The desktop gadget can switch its top-three list between CPU and memory. Main-window, gadget, mini-bar and logical-CPU colors remain consistent.

Process bars compare against the largest process in each column, not total system capacity. Total CPU/memory meters show actual system percentages. See the [README](https://github.com/Sunwood-ai-labs/AERIS#readme) for thresholds and updated screenshots.

Windows x64 installer/portable ZIP, macOS Apple Silicon/Intel DMGs and Linux x64 DEB/AppImage are built and tested by GitHub Actions. Each package includes a SHA-256 sidecar. Windows builds are unsigned; macOS builds use ad-hoc signing without notarization. The interface is Japanese.
