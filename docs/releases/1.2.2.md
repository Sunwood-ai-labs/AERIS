# AERIS 1.2.2

See how apps share CPU and memory with colored stacked bars.

- The overview groups processes with the same executable name, using stable app colors across CPU and memory.
- Each bar shows the largest contributors and an “Other” segment. Hover for amounts, shares and process counts; click an app to inspect its processes.
- CPU can switch between the app breakdown and its existing time history.
- The desktop gadget switches its stacked bar and top-three app list between CPU and memory.
- Individual process comparison bars remain available. Updated screenshots show the actual sample-data interface.

Stacked bars show the composition of measured process totals. Overall system CPU and physical-memory percentages remain separate: process memory includes shared pages and its sum is not physical RAM consumption.

Windows x64 installer/portable ZIP, macOS Apple Silicon/Intel DMGs and Linux x64 DEB/AppImage are built and tested by GitHub Actions. Each package includes a SHA-256 sidecar. Windows builds are unsigned; macOS builds use ad-hoc signing without notarization. The interface is Japanese.
