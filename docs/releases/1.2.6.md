# AERIS 1.2.6

Bring named app rows back below the gadget's stacked bars, so CPU and memory consumers are visible without hovering.

- Show the top three apps, their values, and matching comparison bars in each resource section.
- Add Windows app names for established TCP connections and bound UDP sockets, including IPv4 and IPv6. The network bar shows endpoint counts, not traffic volume or proof of active transfer. Adapter receive/send totals remain visible.
- Add grouped process read/write rates and separate per-device disk I/O and capacity. Windows process I/O also includes network and other devices.
- Use a 340 × 740 full gadget with scrolling for additional volumes; retain the 560 × 76 mini-bar. Update the English/Japanese README and sample screenshot.

Endpoint ownership does not require elevation. Native tests use actual local TCP/UDP sockets to check owning PIDs. macOS/Linux display an explicit unsupported state for endpoint ownership; CPU, memory and I/O continue to use their native counters. Per-app network byte rates are not implemented.

Windows x64 installer/portable ZIP, macOS Apple Silicon/Intel DMGs and Linux x64 DEB/AppImage are built and tested by GitHub Actions. Each package includes a SHA-256 sidecar. Windows builds are unsigned; macOS builds use ad-hoc signing without notarization. The interface is Japanese.
