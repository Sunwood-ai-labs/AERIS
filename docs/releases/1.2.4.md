# AERIS 1.2.4

The desktop gadget now shows CPU and MEM vertically, with both resource breakdowns visible at once.

- CPU appears above MEM; each section has its own stacked bar and top-three app list.
- App colors remain consistent across both sections and the upper memory-capacity bar.
- The full gadget is now 340 × 680, with launch positioning adjusted for the taller window. The 560 × 76 mini-bar is unchanged.
- README screenshots and usage instructions match the new layout.

Windows x64 installer/portable ZIP, macOS Apple Silicon/Intel DMGs and Linux x64 DEB/AppImage are built and tested by GitHub Actions. Each package includes a SHA-256 sidecar. Windows builds are unsigned; macOS builds use ad-hoc signing without notarization. The interface is Japanese.
