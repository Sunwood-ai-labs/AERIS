# AERIS 1.2.0

Everyday desktop task management, with AERIS's translucent main window, gadget and mini-bar.

- Inspect logical CPUs, memory/swap, disks and individual network adapters; view live GPU utilization and memory on Windows.
- Inspect process owners, parents, I/O, command lines and CPU time. Launch a new task, open its file location, terminate a process tree, change Windows priority or restart Explorer.
- Manage common Windows startup entries and services through confirmation dialogs, with protected operations and permission errors surfaced.
- View session/owner resource totals and resettable app history scoped to the current AERIS session.
- Browse updated screenshots and installation instructions in the English README or Japanese guide.

Packages: Windows x64 installer/portable ZIP, macOS Apple Silicon/Intel DMGs, and Linux x64 DEB/AppImage. The interface is Japanese. Individual SHA-256 files accompany each package.

All four native build jobs must pass before publication. Tests exercise disposable process trees, literal launch arguments, startup state changes and Windows service lifecycle operations. See the [verification scope](https://github.com/Sunwood-ai-labs/AERIS/blob/main/docs/task-manager-coverage.md) for manual-test and platform limits.

Windows builds are not Authenticode-signed; macOS builds use ad-hoc signing and are not notarized. See the [README](https://github.com/Sunwood-ai-labs/AERIS#readme) for prerequisites, installation and platform differences.
